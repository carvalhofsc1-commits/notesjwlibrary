Conversor para Notas do JW Library

Digite um texto, escolha um estilo com caracteres especiais, aplique maiúsculas/minúsculas e copie o resultado para colar nas notas do JW Library.

Novo tópico: destaque para notas da ESP 2026 v5.3

Este aplicativo não aplica formatação real. Ele troca as letras por caracteres Unicode parecidos com negrito, itálico, círculos, caixas e símbolos, para dar aparência de destaque em campos que aceitam apenas texto.

1. Texto original

Para formatar várias partes, selecione um trecho e salve a formatação. Para inserir um destaque pronto, escolha “Inserir destaque no cursor”, selecione o destaque e salve.

2. Resultado para copiar

Dica: quando usar “Apenas trecho selecionado”, a visualização mostra como o texto ficará. Para manter essa formatação e aplicar outra em outro trecho, clique em “Salvar formatação aplicada”.

3. Caracteres, ícones e emoticons

Clique para inserir no campo ativo. Os favoritos ficam no topo. Dê dois cliques em um favorito para tirar do topo; dê dois cliques em um item de baixo para mandar para os favoritos.

Adicionar novos caracteres

Cole abaixo novos caracteres, ícones ou emoticons. Eles entrarão na categoria escolhida acima e ficarão salvos neste navegador.

4. Modelos prontos e personalizados

Clique num modelo pronto para adicioná-lo ao campo “Texto do modelo” e usá-lo como base para criar outro. Para editar um modelo existente, selecione-o na lista “Modelo para editar”. Para aplicar um modelo ao texto original, use o campo “Destaque”.

Criar ou alterar modelo

Exportar ou importar modelos

Use esta área para fazer backup dos seus modelos ou enviar seus modelos para outro usuário.

Dica para modelos: use {texto} para marcar onde o texto selecionado deve entrar. Exemplo: ➜ {texto} ⬅. Se o modelo não tiver {texto}, ele será colocado antes do texto.

Os modelos ficam salvos no navegador usando armazenamento local, mas também podem ser exportados para um arquivo .json e importados em outro navegador ou aparelho.

5. Padrões online do administrador

Use esta área quando o app estiver publicado na Vercel junto com o arquivo defaults.json. Assim o usuário pode puxar os padrões mais recentes sem apagar tudo sem querer.
