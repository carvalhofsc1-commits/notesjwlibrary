3. Modelos prontos e personalizados

Clique num modelo pronto para inserir no campo ativo. Se o cursor estiver no texto original, o modelo será inserido ali. Se houver texto selecionado e o modelo tiver {texto}, ele será aplicado ao trecho selecionado; se não tiver {texto}, será inserido antes do trecho.

Criar ou alterar modelo

Também mostrar este modelo em (opcional)

Marque outras categorias para este modelo aparecer nelas também, além da categoria principal escolhida acima.

Categoria oficial padrão: DESTAQUES. Você também pode criar suas próprias categorias em "Gerenciar categorias de modelos", abaixo.

Dica para modelos: use {texto} para marcar onde o texto selecionado deve entrar. Exemplo: ➜ {texto} ⬅. Se o modelo não tiver {texto}, ele será colocado antes do texto.

Gerenciar categorias de modelos

"Renomear" e "Excluir categoria" agem sobre a categoria escolhida em Categoria existente, acima. A categoria DESTAQUES não pode ser renomeada nem excluída. Se a categoria tiver modelos, ao excluir você escolhe se eles são movidos para DESTAQUES ou excluídos junto.

4. Caracteres, ícones e emoticons

Clique para inserir no campo ativo. Os favoritos ficam no topo. Dê dois cliques em um favorito para tirar do topo; dê dois cliques em um item de baixo para mandar para os favoritos.
