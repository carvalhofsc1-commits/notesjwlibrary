Conversor para Notas do JW Library

Digite um texto, escolha as opções, clique em Aplicar e copie o resultado para colar nas notas do JW Library.

Formatar notas da JW Library v8.0

Este aplicativo não aplica formatação real. Ele troca as letras por caracteres Unicode parecidos com negrito, itálico, círculos, caixas e símbolos, para dar aparência de destaque em campos que aceitam apenas texto.

Selecionar

Selecione várias linhas ou parágrafos para transformar em lista. Sem seleção, o app insere apenas o símbolo no cursor.

Selecione um trecho e clique na formatação desejada. A alteração é aplicada e salva automaticamente, mantendo a seleção ativa para outra formatação.

2. Modelos prontos e personalizados

Clique num modelo pronto para inserir no campo ativo. Se o cursor estiver no texto original, o modelo será inserido ali. Se houver texto selecionado e o modelo tiver {texto}, ele será aplicado ao trecho selecionado; se não tiver {texto}, será inserido antes do trecho.

Criar ou alterar modelo

Dica para modelos: use {texto} para marcar onde o texto selecionado deve entrar. Exemplo: ➜ {texto} ⬅. Se o modelo não tiver {texto}, ele será colocado antes do texto.

Os modelos ficam salvos no navegador usando armazenamento local, mas também podem ser exportados para um arquivo .json e importados em outro navegador ou aparelho.

3. Caracteres, ícones e emoticons

Clique para inserir no campo ativo. Os favoritos ficam no topo. Dê dois cliques em um favorito para tirar do topo; dê dois cliques em um item de baixo para mandar para os favoritos.
